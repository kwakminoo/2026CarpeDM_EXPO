## 이 라이선스에 포함되지 않는 것

- **API 키, `.env`, 데이터베이스, 녹음, 학습된 가중치.** 저장소에 올리지 않으며 MIT 배포물에 들어 있지 않다.
- **OpenAI, Google Gemini, ElevenLabs, Chrome 음성 인식.** 호출 시점의 각 서비스 약관을 따른다. 키를 코드·로그·응답에 넣지 않는다.
- **제3자 패키지와 모델.** 각자 라이선스를 유지한다. 이 프로젝트를 다시 배포할 때는 해당 고지를 함께 전달한다.

자주 쓰는 구성 요소와 확인 위치:

| 구성 요소 | 확인 위치 |
| --- | --- |
| Python 패키지 | `poc/backend/requirements.txt`와 각 배포물의 LICENSE |
| Node 패키지 | `mvp/package.json`, `poc/frontend/package.json` |
| Whisper 가중치 | `poc/backend/whisper-models/` (설치 스크립트로 받는 파일, Git 미포함) |
| MediaPipe 자산 | `mvp`의 `npm run setup-offline`이 준비하는 로컬 파일 |
| 한글 폰트 Pretendard | CDN 로드. 실패하면 시스템 한글 폰트로 그린다 |

패키지 라이선스가 MIT와 다르면 그 패키지 고지가 우선한다. 의존성 목록을 이 문서에 고정해 두지 않는다. 배포 전에 설치본의 라이선스 파일을 다시 확인한다.

## 시나리오와 문서

시나리오 팩, 시드 문장, `docs/`의 기획·안내 문서는 소프트웨어와 함께 제공되는 문서다. 복사·수정·배포 시 루트 `LICENSE`의 저작권 표시와 허가 표시를 남긴다.

학교 과제·전시 규정으로 별도 공개 제한이 있으면 그 규정이 저장소 밖 제출물에는 적용될 수 있다. 저장소 안의 소스에 대한 라이선스 문장 자체는 루트 `LICENSE`만 바꾼다.
